# BAi709 Module Repository

A starter repository for BAi709 student modules. Use this template to create a private repository for your own coursework.

## Structure

- `data/` — datasets shared by the module
- `comparing-two-groups/` — notebooks and materials for comparing two groups

## Data paths

From a topic folder, load shared datasets with paths such as `../data/ab_test_website.csv`.

## Environment

The included dev container installs the Python dependencies when the Codespace is created. Open a notebook in Jupyter to get started.
